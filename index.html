Read the t-stat, not the alpha. With three years of daily data and 9% idiosyncratic vol, an alpha of 150 bps a year is roughly a t-stat of 0.9 — indistinguishable from zero. Drag idiosyncratic vol down and watch the same alpha become “significant” without becoming any more real. That is the whole argument of weeks 2, 7 and 8.

The four answers that are always wrong

  • A single number with no interval. “VaR is $1.2 m” is not a risk report; “VaR 95% 1-day is $1.2 m, with 14 exceedances in 500 days against 25 expected” is.
  • An in-sample number. If the parameter was chosen on the data it is measured on, the number is a description of the past, not a forecast.
  • A number with no cost. Gross of fees, gross of spread, gross of impact — three ways to turn a losing strategy into a slide.
  • A number with no count of attempts. The best of 200 backtests has a Sharpe of about 2.5 even when every one of them is pure noise. Say how many you ran.

Smoke test: RED · 0 of 5 steps

No GPU, no cluster, no cloud account, no brokerage account and no vendor subscription is needed for any week of this course. A cached offline snapshot ships with the starter repo, so no lab depends on the network — and for the arena weeks, the offline simulator (make sim) is always an acceptable substitute for the live venue.

If something is red

yfinance returns an empty frame

Usually a rate limit or a ticker that no longer exists, and both come back as an empty frame rather than an exception — which is exactly how a survivorship bug enters a panel silently.

Fix: assert on df.shape immediately after every download, cache to Parquet on first success, and read the cache thereafter. Never let an empty frame become a row of zeros.

Adj Close and Close are identical

You called yf.download(...) with auto_adjust=True (the modern default), so Close has already been adjusted in place and the raw close is gone.

Fix: pass auto_adjust=False when you want both series — week 1 asks you to re-derive the adjustment, which is impossible if you only have the adjusted one.

pandas-datareader cannot reach FRED or Ken French

Both are plain HTTP endpoints, and a corporate or campus network proxy sometimes blocks them, and the reader surfaces that as a parse error rather than a network error.

Fix: use the cached snapshot in the starter repo (data/cache/), and treat the network as an optimisation, not a dependency.

arch or scipy will not build

Weeks 4–5 need compiled wheels, and those are the ones that bite on a mixed Mac/Windows cohort with a too-new Python.

Fix: Python 3.11 exactly, in a fresh venv, then pip install --only-binary :all: arch scipy so pip refuses to compile from source.

Your team token is in a file you are about to commit

The team token authorises trades against your team’s capital in the arena weeks. It belongs in a .gitignored .env and nowhere else — not in a notebook cell, not in a screenshot, not in a chat message.

Fix: git check-ignore -v .env before your first commit; if you have already pushed one, rotate it immediately.

Reproducibility is graded. Every deliverable in this course is read from a repo that runs on a clean checkout, with data fetched by a script and cached — never from a screenshot of a number. A result you cannot re-run is not a result.
